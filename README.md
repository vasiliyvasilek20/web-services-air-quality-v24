## Запуск локально

Нужен запущенный Docker Desktop (или Docker Engine с Docker Compose).
Перейдите в каталог проекта, содержащий этот README.

### 4 контейнера — по методичке и для видео-защиты

```sh
docker compose up --build -d --wait
```

Откройте http://localhost:8080.
Контейнеры: `frontend`, `backend`, `db`, `web-service`.
Backend обращается к `http://web-service:8001/aqi` по HTTP внутри сети Docker Compose.
Все 4 сервиса объявлены в корневом `docker-compose.yml`.

### 3 контейнера — по исходной краткой формулировке задания

```sh
docker compose -f compose.three.yml up --build -d --wait --remove-orphans
```

Контейнеры: `frontend`, `backend`, `db`. Веб-сервис AQI работает как модуль backend.
Оба режима используют одинаковый том БД. Данные сохраняются при смене режима.

Для возвращения к 4 контейнерам:

```sh
docker compose up --build -d --wait
```

`compose.four.yml` сохранён для совместимости с прежней командой запуска; основной файл уже содержит все 4 сервиса.

## Что проверить на фронте

1. Нажмите **«Загрузить зоны из БД»**: появятся Москва, Санкт-Петербург и Казань.
2. Выберите зону и нажмите **«Получить AQI и сохранить»**. Backend запрашивает эмулятор по координатам и записывает результат в PostgreSQL.
3. Нажмите **«Загрузить историю из БД»**: появятся сохранённые наблюдения.
4. Через «Добавить экологическую зону» создайте свою зону.
5. Кнопки «Название» и «Удалить» позволяют переименовать и удалить зону. Удаление требует подтверждения; её история удаляется каскадно.

## Учебный эмулятор AQI

Методичка разрешает локальный микросервис-эмулятор. API-ключи и внешний интернет во время работы приложения не требуются; интернет нужен для первоначальной загрузки образов и Python-зависимостей.

AQI детерминированно получается из SHA-256 строки координат с точностью 6 знаков: первые два байта хэша преобразуются в число, затем берётся остаток от деления на 301. Для одинаковых координат возвращается одинаковое учебное значение 0–300. Категории используют границы 50 / 100 / 150 / 200 / 300 / 500. **Это синтетические демонстрационные данные, а не реальные измерения или прогноз.** Это явно указано в интерфейсе и поле `source` каждой записи.

## Архитектура

- Frontend: HTML/CSS/JavaScript, сервер Nginx и прокси `/api/`.
- Backend: Python 3.13, HTTP REST API, драйвер psycopg 3.
- БД: PostgreSQL 17, `db/init.sql` автоматически создаёт таблицы и 3 начальные зоны.
- Web-service: Python 3.13; в режиме 4 контейнеров это отдельный HTTP-сервис.
- Стандартная bridge-сеть Compose; браузер работает с API через тот же адрес Nginx.
- `depends_on` с `healthcheck` задаёт порядок готовности БД, backend и web-service.
- Именованный том `db_data` сохраняет БД. БД и backend не публикуют порты хоста; фронт доступен локально на `127.0.0.1:8080`.

Таблица `zones`: id, название, широта, долгота.
Таблица `measurements`: id, зона, AQI, категория, источник, время проверки.
Координаты существующей зоны не меняются, чтобы её история оставалась привязанной к месту. Для других координат создаётся новая зона.

## REST API

| Метод | Путь | Действие |
|---|---|---|
| GET | `/api/zones` | Зоны и последний AQI из БД |
| POST | `/api/zones` | Создать зону: name, latitude, longitude |
| PUT | `/api/zones/{id}` | Переименовать зону; передать name и прежние координаты |
| DELETE | `/api/zones/{id}` | Удалить зону и её историю |
| POST | `/api/zones/{id}/check` | Получить AQI по координатам зоны и записать в БД |
| GET | `/api/history` | Последние 100 наблюдений из БД |

Backend `/health` проверяет соединение с БД.
Web-service `/health` проверяет готовность; `/aqi?latitude=55.7558&longitude=37.6173` возвращает AQI.

## Проверка

После запуска любого режима:

```sh
python3 tests/smoke.py
docker compose ps
```

Smoke-проверка создаёт временную зону, проверяет CRUD, вызов AQI, сохранение истории, отклонение некорректных координат и удаляет временные данные.

Проверка сохранности: получите AQI, выполните `docker compose down`, затем запустите выбранный режим снова. Зоны и история останутся.

## Настройки и остановка

Необязательно: скопируйте `.env.example` в `.env` для изменения порта и локального пароля БД. Значение по умолчанию — учебный пароль для локального запуска. Существующий PostgreSQL-том сохраняет пароль, заданный при первой инициализации.

```sh
docker compose down
```

Для остановки режима с тремя контейнерами:

```sh
docker compose -f compose.three.yml down
```

Команда `down` сохраняет данные. Добавление `-v` удалит том со всей БД; используйте это только для полного сброса лабораторной.
